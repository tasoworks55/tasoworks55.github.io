プライバシーポリシー

最終更新日：2026年11月21日

pixel-shorts-upload（以下「本ツール」）は、運営者が自分の YouTube チャンネルに動画を投稿するためだけに使う個人用ツールです。

使う情報

  • Google アカウントへのログインで得る、YouTube への動画アップロードの権限（youtube.upload）だけを使います。
  • 投稿する動画ファイルと、そのタイトル・説明文・タグを YouTube に送ります。

保存と共有

  • ログイン情報（リフレッシュトークン）は、運営者の PC の中だけに保存します。
  • 個人情報や利用データを集めたり、第三者に渡したり、売ったりすることはありません。広告や分析には使いません。

YouTube と Google

本ツールは YouTube API Services を使います。利用にあたっては YouTube 利用規約と Google プライバシーポリシーが適用されます。

権限の取り消し

本ツールに与えた権限は、Google アカウントのセキュリティ設定からいつでも取り消せます。

お問い合わせ

このページを置いている GitHub リポジトリの Issues からご連絡ください。

Privacy Policy

Last updated: November 21, 2026

pixel-shorts-upload ("the tool") is a personal tool the operator uses only to upload videos to the operator's own YouTube channels.

  • It uses only the YouTube upload permission (youtube.upload) granted at Google sign-in, and sends video files with their title, description and tags to YouTube.
  • The sign-in credential (refresh token) is stored only on the operator's own computer.
  • No personal or usage data is collected, shared, sold, or used for advertising or analytics.
  • The tool uses YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy apply.
  • Access can be revoked at any time at Google Account permissions.
  • Contact: open an issue in the GitHub repository that hosts this page.
